# GameOn — Produktroadmap

> Uppdaterad: 2026-06-07

---

## Nuläge ✅

Plattformen är fullt fungerande med 30+ uppdrag, realtids-leaderboard, power-ups, fotouppdrag, custom missions, PDF-rapport, Stripe-betalning, AI-chatbot och superadmin-analytics.

---

## Vecka 1

- 📱 **Mobilvy för admin** — responsiv AdminScreen för telefon, fungerar fortfarande perfekt på stor skärm

---

## Vecka 2

- 🌐 **i18n** — svenska + engelska, adminval per spel
- 🎮 **Spelmallar** — "After Work", "IT Onboarding" etc., förvalda uppdrag direkt vid skapande
- 🖼️ **AI-bedömning av fotouppdrag** — Claude Vision föreslår poäng, admin godkänner/ändrar

---

## Vecka 3–4

- 🎙️ **Presentatörsläge** — stor-skärms-vy för projektor/TV med live-leaderboard och poänganimationer, ingen admin-kontroll
- 🤖 **AI-genererade uppdrag** — admin beskriver ett tema, AI genererar komplett uppdragsset med frågor och svarsalternativ

---

## Månad 2

- 🌍 **Stöd för 500+ spelare simultant** — arkitekturförbättringar (connection pooling, rate limiting, edge functions) för stora events och konferenser

---

## Kvartal 3+

- 🎥 **Videouppdrag** — lag spelar in korta klipp, AI eller admin bedömer
- 🤖 **AI Game Host** — AI-karaktär som kommenterar spelet live, reagerar på poäng och power-ups, skapar spelshow-känsla
- 🏆 **Turneringsläge** — knockout-bracket med flera rundor

---

## Prioriteringsprinciper

1. **Spelupplevelsen först** — allt som gör spelet roligare trumfar admin-verktyg och infra
2. **Löser verkliga problem** — funktioner kunder faktiskt stöter på, inte hypotetiska
3. **Intäktsdriven** — funktioner som motiverar uppgradering och förnyelse
4. **Datadrivet** — superadmin-analytics visar vad som funkar → bygg mer av det
